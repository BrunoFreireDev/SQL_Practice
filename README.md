# SQL Practice

Repositório dedicado aos meus estudos, evolução e prática em banco de dados relacional. Aqui estão reunidas consultas, scripts, exercícios e rotinas **desenvolvidos integralmente utilizando MySQL** para consolidar o domínio de SQL.

---

## Estrutura do Repositório

O conteúdo está organizado por categorias de complexidade e funcionalidade:

* **`00_Select`** → Consultas básicas de seleção, filtros iniciais e projeção de colunas.
* **`01_Where`** → Aplicação de condições, operadores lógicos e filtros avançados.
* **`02_Having`** → Filtros aplicados a resultados agrupados utilizando funções de agregação.
* **`03_Joins`** → Consultas relacionais combinando tabelas (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, etc.).
* **`04_Aggregations`** → Utilização de funções estatísticas e de resumo (`COUNT`, `SUM`, `AVG`, `GROUP BY`).
* **`05_Subqueries`** → Consultas aninhadas e subconsultas para cenários complexos.
* **`06_Views`** → Criação e manipulação de visões para reutilização de queries.
* **`07_Procedures`** → Desenvolvimento de procedimentos armazenados (`Stored Procedures`) para automação e lógica no banco.
* **`08_Triggers`** → Criação de gatilhos para execução automática de eventos em tabelas.
* **`09_Update`** → Comandos e boas práticas para atualização de registros.
* **`10_Delete`** → Rotinas de remoção segura de dados.
* **`11_Window_Function`** → Exploração e aplicação de funções de janela (`ROW_NUMBER()`, `RANK()`, etc.).
* **`modelagem_database_estudos`** → Arquivos de modelagem, criação de tabelas e esquemas para os cenários de prática.

* **Ambiente Local:** WampServer

* **Editores de Código:** VS Code, NotePad++

## Objetivo

Praticar e aprofundar o conhecimento técnico em manipulação, consulta e administração de bancos de dados relacionais com foco em MySQL, simulando cenários reais e aprimorando a lógica de desenvolvimento.
